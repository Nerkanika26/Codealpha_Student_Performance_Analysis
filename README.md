CodeAlpha Educational Performance & Resource Allocation

📌 Project Overview

This project was developed as part of the CodeAlpha Power BI Internship – Task 4: Educational Performance & Resource Allocation.

The project analyzes student academic performance and educational resources using Power BI. The interactive dashboard provides insights into student performance, resource usage, and resource allocation to support data-driven decisions in education management.

🎯 Objective

The main objectives of this project are:

- Analyze student academic performance
- Monitor student performance trends
- Analyze educational resource usage
- Identify resource gaps
- Compare academic performance across different categories
- Support data-driven education management
- Improve resource allocation decisions

🛠️ Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel / CSV
- Data Analysis
- Data Visualization

📊 Dashboard Pages

1. Student Performance Overview

This page provides an overview of student academic performance.

Key metrics and analysis include:

- Total Students
- Average Marks
- Average Performance
- Pass Rate
- Average Attendance
- Student performance distribution
- Performance by department/class
- Subject-wise performance

2. Resource Allocation

This page focuses on educational resource availability and utilization.

The analysis includes:

- Resource availability
- Resource utilization
- Resource distribution
- Resource gaps
- Department/class-wise resource analysis
- Student-to-resource comparison

This helps identify areas where additional resources may be required.

3. Performance & Resource Insights

This page connects academic performance with educational resources.

The analysis includes:

- Performance by department/class
- Attendance vs performance
- Resource availability vs performance
- Resource gap analysis
- Student-resource relationship
- Areas requiring better resource allocation

📈 Key KPIs

The dashboard tracks important educational metrics such as:

🧹 Data Preparation

The dataset was prepared using Power Query.

The data preparation process included:

- Removing duplicate records
- Handling missing values
- Correcting data types
- Cleaning categorical fields
- Formatting numerical fields
- Preparing the dataset for analysis

🧮 DAX

DAX measures were created to calculate important educational metrics such as:

- Total Students
- Average Marks
- Pass Rate
- Average Attendance
- Resource Utilization
- Resource Gap
- Student-Teacher Ratio

These measures were used to create dynamic KPIs and interactive visualizations.

💡 Key Insights

The dashboard helps identify:

- Student performance patterns
- Differences in academic performance across categories
- Attendance and performance patterns
- Resource availability and utilization
- Areas with resource gaps
- Areas that may require better resource allocation

The insights are based on the analysis of the selected educational dataset.
